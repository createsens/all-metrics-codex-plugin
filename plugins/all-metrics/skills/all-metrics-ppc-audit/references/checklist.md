# Чек-лист PPC-аудита

Каждая проверка возвращает один из статусов: `ok`, `issue`, `not_available` (API не отдаёт данные), `not_connected` (платформа не подключена). Статус `not_available` никогда не превращается в `ok`.

Приоритеты: `P0` — прямая потеря денег или отсутствие измерения; `P1` — значимая неэффективность; `P2` — гигиена и потенциал роста.

## 1. Структура аккаунта и кампаний

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Активные кампании без расходов за период | список кампаний + отчёт по расходам | P1 |
| Кампании с расходами, но без конверсий за период при достаточном объёме кликов | отчёт по расходам и конверсиям | P0 |
| Дубли кампаний с пересекающейся семантикой и гео | список кампаний + ключевые слова | P1 |
| Приостановленные кампании, потребляющие бюджет через связанные сущности | статусы кампаний и групп | P2 |
| Группы объявлений без активных объявлений | группы + объявления | P1 |
| Группы с одним объявлением без альтернативы для ротации | объявления по группам | P2 |

## 2. Стратегии, бюджеты и ставки

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Автостратегия с целевым CPA или ROAS при недостаточном числе конверсий для обучения | стратегия кампании + конверсии за период | P0 |
| Бюджет, ограничивающий показы (доля потерянных показов по бюджету) | метрики доли показов | P1 |
| Ручные ставки ниже нижней границы верхнего блока | ставки + рекомендации ставок | P1 |
| Смена стратегии внутри анализируемого периода | история изменений | P1 |
| Кампании с одинаковой целью, конкурирующие за один запрос | ключевые слова + поисковые запросы | P1 |

## 3. География и расписание

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Гео шире, чем зона обслуживания бизнеса | настройки гео | P0 |
| Расходы в регионах без конверсий | отчёт по регионам | P1 |
| Тип присутствия в гео допускает показы по интересу, а не по местоположению | настройки гео | P1 |
| Расписание показов не учитывает часы работы при телефонных конверсиях | расписание + CallRail при наличии | P2 |
| Корректировка по времени противоречит фактическому распределению конверсий | корректировки + отчёт по часам | P2 |

## 4. Ключевые слова и минус-слова

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Пересечение ключевых и минус-слов, блокирующее показы | аудит конфликтов ключей | P0 |
| Широкое соответствие и автотаргетинг без ограничивающих минус-слов | ключевые слова + автотаргетинг + минус-слова | P0 |
| Ключи с расходом и нулевой конверсией выше порога кликов | отчёт по ключам | P1 |
| Дубли ключей внутри одной кампании и между кампаниями | ключевые слова | P1 |
| Ключи со статусом «мало показов» и нулевой историей | статусы ключей | P2 |
| Минус-слова заданы только на уровне группы, не на уровне кампании или библиотеки | минус-слова по уровням | P2 |

## 5. Поисковые запросы

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Нерелевантные запросы с расходом выше порога | отчёт по поисковым запросам | P0 |
| Информационные и «бесплатно/своими руками» запросы в продающей кампании | отчёт по поисковым запросам | P1 |
| Брендовые запросы конкурентов без осознанной стратегии | отчёт по поисковым запросам | P2 |
| Конвертящие запросы, не вынесенные в отдельные ключи | запросы + ключи | P2 |
| Доля расхода по запросам, не сопоставленным с ключами | отчёт по запросам и ключам | P1 |

## 6. Объявления, расширения, посадочные

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Отклонённые или ограниченные объявления | статусы модерации | P0 |
| Не заполнены быстрые ссылки, уточнения, телефон и другие доступные расширения | расширения | P1 |
| Отсутствие ключевой фразы в заголовке при точном коммерческом интенте | объявления + ключи | P2 |
| Посадочная отдаёт редирект или ошибку | Website `inspect` при подключённом источнике | P0 |
| Разные объявления группы ведут на разные посадочные без цели теста | объявления | P2 |

## 7. Аудитории, ретаргетинг, корректировки

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Ретаргетинг отсутствует при достаточном трафике сайта | ретаргетинг + аналитика | P1 |
| Списки аудиторий не набирают минимальный размер | аудитории | P1 |
| Корректировки по устройствам противоречат фактическому CPA по устройствам | корректировки + отчёт по устройствам | P1 |
| Исключение текущих клиентов не настроено при продаже разовой услуги | аудитории и исключения | P2 |

## 8. Отслеживание конверсий

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| В кампании нет ни одной цели или действия-конверсии | цели кампании | P0 |
| Счётчик аналитики не привязан или привязан не тот | аудит отслеживания | P0 |
| Автометки `gclid`/`yclid` отключены, а ручная разметка неполная | аудит отслеживания | P0 |
| Как конверсия учитываются микродействия наравне с заявками | список целей и их веса | P1 |
| Конверсии импортируются из CRM, но окно атрибуции не согласовано с циклом сделки | аудит отслеживания + CRM | P1 |
| Дублирование конверсий из-за нескольких источников одного события | список целей | P1 |

## 9. История изменений

| Проверка | Источник подтверждения | Приоритет |
| --- | --- | --- |
| Изменения, совпадающие по дате со сломом динамики | история изменений + дневная динамика | P1 |
| Автоматические изменения платформы, не согласованные с командой | история изменений | P1 |
| Массовые изменения ставок или бюджетов внутри периода | история изменений | P1 |
| Отсутствие изменений при устойчиво падающих показателях | история изменений | P2 |

Совпадение по дате — только корреляция. Причинность утверждать нельзя без отдельного эксперимента.
