# Предустановки таргетинга

Передавать эти значения как человеческие `language` и `locations` через `keyword_planner(operation=options)`. Не запрашивать и не хранить Google criteria ID.

## Языки

| Русское название | Название Google для поиска |
|---|---|
| Русский | Russian |
| Английский | English |
| Румынский | Romanian |
| Немецкий | German |
| Украинский | Ukrainian |
| Французский | French |
| Испанский | Spanish |
| Португальский | Portuguese |
| Итальянский | Italian |
| Польский | Polish |

Все десять языков существуют в актуальном списке языкового таргетинга Google Ads. Перед запросом подтвердить разрешение через `targeting_resolution`.

Отдельного казахского языка в текущем официальном списке Google Ads нет.

## Страны

| Русское название | Название Google | ISO |
|---|---|---|
| Молдова | Moldova | MD |
| США | United States | US |
| Казахстан | Kazakhstan | KZ |
| Беларусь | Belarus | BY |
| Канада | Canada | CA |
| Германия | Germany | DE |
| Румыния | Romania | RO |
| Великобритания | United Kingdom | GB |
| Украина | Ukraine | UA |
| Франция | France | FR |

Для каждой страны выполнить `options` с названием, затем проверить `targeting_resolution`, у которого:

- название и ISO-код совпадают;
- `target_type` соответствует стране;
- статус активен и допускает таргетинг.

Наличие страны в таблице не гарантирует её текущую рекламную доступность. Если All Metrics не возвращает активный точный результат, не подставлять старый ID и сообщить об ограничении.
