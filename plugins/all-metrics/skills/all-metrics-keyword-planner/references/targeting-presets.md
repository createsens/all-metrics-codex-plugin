# Предустановки таргетинга

Использовать эти значения как удобные названия для поиска через `keyword_planner(operation=options)`. Не передавать названия вместо `language_id` или `geo_target_ids` и не хранить найденные ID как вечные константы.

## Языки

| Русское название | Название Google для поиска |
|---|---|
| Русский | Russian |
| Английский | English |
| Румынский | Romanian |
| Немецкий | German |
| Украинский | Ukrainian |
| Французский | French |
| Испанский | Spanish |
| Португальский | Portuguese |
| Итальянский | Italian |
| Польский | Polish |

Все десять языков существуют в актуальном списке языкового таргетинга Google Ads. Перед запросом выбрать точный объект из `options.languages`.

Не использовать ошибочные подписи текущего ручного справочника All Metrics:

- `1024` - не казахский;
- `1035` - не украинский;
- отдельного казахского языка в текущем официальном списке Google Ads нет.

| Беларусь | Belarus | BY |

| Румыния | Romania | RO |
| Великобритания | United Kingdom | GB |
| Украина | Ukraine | UA |
| Франция | France | FR |

Для каждой страны выполнить отдельный поиск `options` с `geo_query`, затем выбрать результат, у которого:

- название и ISO-код совпадают;
- `target_type` соответствует стране;
- статус активен и допускает таргетинг.

Наличие страны в таблице не гарантирует её текущую рекламную доступность. Если Google ограничивает страну или All Metrics не возвращает активный точный результат, не подставлять старый ID и сообщить об ограничении.
