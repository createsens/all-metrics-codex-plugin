# Операции инструмента `website`

Полный список операций, который принимает MCP-инструмент `website` сервера All Metrics 3.1.0 и выше.

| Операция | `result_source` | Назначение | Обращается к сайту |
| --- | --- | --- | --- |
| `list` | — | Все сайты пользователя; переживает временный таймаут доступности | нет |
| `inspect` | `live_inspect` | Одиночное живое наблюдение одной страницы | да |
| `start_crawl` | `new_crawl` | Запуск нового обхода, создаёт UUID | да |
| `crawl_status` | — | Статус запущенного обхода до терминального состояния | нет |
| `list_audits` | `saved` | История сохранённых аудитов | нет |
| `latest_audit` | `saved` | Последний завершённый аудит | нет |
| `get_audit` | `saved` | Сводка аудита по UUID | нет |
| `pages` | `saved` | Постраничные данные обхода | нет |
| `page` | `saved` | Данные одной страницы обхода | нет |
| `issues` | `saved` | Проблемы обхода | нет |
| `findings` | `saved` | Структурированные находки с серьёзностью | нет |
| `audit` | `saved` | Полный сохранённый аудит | нет |
| `checks` | `saved` | Перечень выполненных проверок и их результат | нет |
| `performance` | `saved` | PageSpeed Insights и CrUX | нет |
| `robots` | `saved` | robots.txt и разбор директив | нет |
| `sitemaps` | `saved` | Карты сайта и ошибки разбора | нет |
| `crawl_urls` | `saved` | Все URL обхода, включая исключённые | нет |
| `compare` | `saved` | Сравнение двух обходов по UUID | нет |
| `visual` | `saved` | Скриншоты страниц | нет |

## Ограничения

- Общие инструменты `list_fields`, `preview_data` и `start_query` не поддерживают источник `website`. Использовать только инструмент `website` и MCP-ресурсы обхода.
- Один отчёт строится по одному UUID обхода. Смешивать данные разных обходов можно только через `compare` и с явной оговоркой.
- Данные сохранённого обхода неизменяемы. Повторный вызов сохранённой операции не обновляет данные и не является новой проверкой.
- Добавление публичного сайта не требует OAuth, не подтверждает владение и не запускает ни Browserless, ни PSI, ни CrUX, ни обход.
- Временный таймаут доступности — свидетельство о достижимости сайта в момент проверки, а не об удалении источника.

## PSI и CrUX

- PageSpeed Insights — лабораторный прогон в контролируемых условиях. Зависит от выбранной стратегии (mobile или desktop) и момента запуска.
- CrUX — полевые данные реальных пользователей Chrome за скользящие 28 дней. Доступны не для всех сайтов и не для всех URL.
- Не подменять одно другим и не усреднять их в один показатель. Всегда указывать устройство и дату сбора.

## Серьёзность находок

| Уровень | Смысл | Реакция |
| --- | --- | --- |
| `critical` | Блокирует индексацию или доступность | Немедленно, до остальных работ |
| `high` | Значимо ухудшает видимость или поведение | В текущем спринте |
| `medium` | Снижает качество, но не блокирует | В плане на месяц |
| `low` | Гигиена и мелкие улучшения | По остаточному принципу |
| `info` | Наблюдение без требования действий | Только в контексте |

Если сервер вернул иной набор уровней, использовать фактические значения ответа и не переводить их в эту шкалу молча.
